# UART Controller with cocotb Verification
A synthesizable UART (Universal Asynchronous Receiver-Transmitter) core designed for FPGAs (specifically tested for Altera MAX 10). This project demonstrates a modern digital design workflow by combining traditional Verilog RTL with Python-based hardware verification.

📂 Project Structure
rtl/: Contains the four core Verilog modules: uart_tx.v, uart_rx.v, uart_top.v, and the baud rate generator.

schematic/: Contains architectural visualizations generated by both Quartus Prime (Industry Standard) and Yosys (Open Source).

test/: Contains the cocotb testbench (test_uart.py) and the Makefile for automated simulation.

waveform/: Contains the VCD simulation data and a PDF export of the timing diagrams for quick review.

🛠️ Toolchain
HDL: Verilog (RTL)

Simulation: Icarus Verilog

Verification: cocotb (Python-based)

Synthesis: Yosys & Quartus Prime

Visualization: GTKWave

🏗️ Architecture & Features
Baud Rate: 9600 bps (calculated from a 50 MHz system clock).

Receiver Logic: Features a half-divider sampling clock to ensure bits are sampled at the stable center of the pulse.

Loopback Design: The uart_top.v module connects the TX and RX internally, allowing for full-path data validation.

🧪 Verification Results
The testbench validates the loopback by sending test vectors like 0x55, 0xA5, 0x3C, and 0xFF.

Key Observation: In the waveform, the receiver successfully latches and validates the byte 0x55 even as the transmitter begins preparing the next byte 0x45, proving the robustness of the FSM handshakes.

🚀 How to Run
Ensure python3, icarus-verilog, and cocotb are installed.

Navigate to the test/ directory.

Run the command:

Bash
make
Open the waveform:

Bash
gtkwave waveform/your_file.vcd
